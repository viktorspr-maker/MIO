Mioty onboarding test

Three ways to get a Mioty Gateway and its kit of devices into Aranet Cloud — from the EP.02 journey map. Each one can be walked through on a phone with real QR codes. Wireframe prototype; nothing here is connected to anything.

🖨 Print the QR sheet (A4) first: one gateway code, one kit code, 25 device codes, one .csv link.
1I have a KIT

Gateway plus a boxed kit. One code registers every device in the kit at once.

  1. Scan the Gateway QR with the phone camera → Hello Mioty → Start
  2. Existing user → Login → Choose workspace
  3. I have a KIT → paste or scan the Kit QR → Add
  4. Connecting Devices → Successfully connected
Start scenario 1
2Scan QR codes

Devices without a kit code. Scan each device sticker in a row; the app counts them.

  1. Gateway QR → Hello Mioty → Login → Choose workspace
  2. Scan QR code → camera opens inside the app → hold the device QRs one after another
  3. The button counts: Add (n) Mioty devices → tap it
  4. Connecting Devices → Successfully connected
Start scenario 2
3Upload .csv file

A prepared device list. Save it to the phone, then pick it from the app.

  1. Scan the .csv QR with the phone camera → the file downloads to the phone
  2. Gateway QR → Hello Mioty → Login → Choose workspace
  3. Upload .csv file → Choose a .csv from this phone → Add
  4. Connecting Devices → Successfully connected
Start scenario 3

Every scenario ends on “Successfully connected” with a button back to this page. On a laptop the app shows inside a phone frame and the camera is faked (tap the frame). On a phone, open this page over HTTPS for the real camera.
